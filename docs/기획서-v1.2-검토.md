# 상세 기획서 v1.1 → v1.2 검토 및 반영

새 문서는 서사상의 우연을 설명하고 퍼즐의 추론 과정을 강화하는 수정이어서 게임에 반영했습니다. 원본 문서 두 파일은 수정하지 않았습니다.

| 항목 | 주요 차이와 판단 | 반영 결과 |
| --- | --- | --- |
| 컴퓨터의 판매 경위 | 윤서가 타인에게 의도적으로 판 것으로 읽히던 흐름을, 정민에게 인계할 보관 기기의 오판매로 명확히 함 | 시작 문서·접수·메일·공통 후일담 수정 |
| P3 기록 비교 | 이름과 보관 ID의 대응, 현재 표와 원본 표를 분리해 비교 과정 강화 | F08·F09 및 퍼즐 안내 수정 |
| P4 백업 검증 | R2 선택만으로 끝내지 않고 R1의 순서 중복·누락과 R3의 원본 덮어쓰기를 구별 | 후보와 탈락 이유 입력, 항목별 오답, 입력 초안 저장 |
| P5 사건 재구성 | 시간 재입력 대신 사건 카드 정렬과 세 주장에 대한 판단·근거 선택 | 순서 이동, 주장별 판정, 최소 근거와 유효한 추가 근거 허용 |
| 선택과 엔딩 | 신원 유지·보호 및 자료·요약 전달마다 이득과 부담을 드러냄 | 네 엔딩 답신·후속 기록·상태 표시 수정, B와 C 제목 변경 |
| 마지막 인계 | P5 완료와 인계 준비 상태를 구별하고 마지막 메일의 늦은 열람 처리 | 메일 확인 후 최종 검토로 연결, P5 재풀이 방지, 체크포인트 중복 생성 방지 |
| 저장 | 새 퍼즐과 분기에 맞춰 저장 형식 변경 | v3에 새 진행 저장, 기존 v2 데이터 보존 및 새 조사 안내 |

기존 요청인 힌트 제거, 일정한 아이콘 영역, 더블클릭 열기, 창 크기 조절, 스크롤 위치 유지, 테마 스크롤바와 사진 팝업 바깥 클릭 닫기는 유지했습니다.

## 확인한 사항

- 브라우저에서 P1~P5 진행과 네 엔딩 도달.
- 백업 오답 사유 구분, 입력 초안과 새로고침 후 이어하기.
- P5의 추가 유효 근거 허용과 마지막 메일을 늦게 읽는 진행.
- 마지막 선택·증언자 선택 체크포인트에서 재진행.
- 규칙 테스트의 저장 검증, 접근 조건과 인계 준비 반복 실행.

예상 플레이 시간은 기획 목표이며 신규 플레이어 실측은 하지 않았습니다. 브라우저 전체 호환성 및 다수 사용자 플레이테스트는 별도 검증이 필요합니다.
