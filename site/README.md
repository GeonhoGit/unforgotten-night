# 중고 컴퓨터의 비밀 — 지워지지 않은 밤

한국어 가상 데스크톱 추리게임입니다. 상세 기획서 v1.2를 반영한 콘텐츠 16개, 퍼즐 5개, 두 분기와 네 엔딩, 로컬 자동 저장, 두 체크포인트를 포함합니다.

v1.2에서는 보관 기기의 오판매 경위, 두 기록표 비교, 백업 탈락 사유, 사건 순서와 주장별 근거 판정, 선택별 후속 답신을 반영했습니다. 힌트는 제공하지 않습니다. 더블클릭 열기, 창 크기 조절, 스크롤 위치 유지와 사진 팝업 바깥 클릭 닫기를 유지합니다.

저장 형식은 schema 3 / content ep1-1.2.0입니다. 이전 v2 저장은 삭제하지 않지만 새 퍼즐과 호환되지 않아 새 조사가 필요합니다. v1.2 진행과 입력 초안은 별도 저장합니다.

실제 파일 접근·메일 전송·회원가입·결제는 없습니다. 조사는 브라우저 저장소에 저장됩니다. 홈페이지 예상 플레이 시간은 기획 목표이며 신규 플레이어 실측값이 아닙니다.

`dist` 디렉터리를 정적 HTTP 서버로 제공합니다. 외부 폰트를 읽지 못하면 시스템 글꼴로 대체됩니다. 게임 데이터와 퍼즐 정답은 클라이언트에 포함되며 보안 기능이 아닙니다.

사진 2개는 이 프로젝트를 위해 OpenAI 이미지 생성으로 제작했습니다. 필수 숫자·날짜는 DOM 텍스트로도 제공합니다. 아이콘은 자체 SVG이며 조작음은 Web Audio로 생성합니다.

검증: v1.2 브라우저에서 다섯 퍼즐, 네 엔딩, 두 체크포인트, 입력 초안과 새로고침 후 이어하기를 확인했습니다. 마지막 메일을 늦게 읽어도 P5를 다시 풀지 않는 흐름을 확인했습니다. 순수 규칙 테스트에서 정답 정규화, 백업 오답 사유, 사건 순서와 주장별 최소 근거 및 추가 근거 허용, 인계 준비의 반복 실행, 저장 유효성 검사를 통과했습니다. 대규모 플레이테스트와 Chrome/Edge/Firefox 전체 호환성 인증은 아직 하지 않았습니다.
